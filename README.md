# ☕ Meus Primeiros Passos no Java

Fala aí! Sou estudante de **Ciência da Computação** e este repositório é onde estou guardando os meus primeiros códigos "reais". 

Não são sistemas complexos ainda, mas cada um desses arquivos representa uma barreira que eu quebrei aprendendo lógica de programação, loops e como o Java funciona de verdade.

---

## 📂 O que eu já consegui fazer:

### 🎮 [Jogo de Adivinhação](./src/JogoAdivinhacao.java)
Aquele clássico: o PC escolhe um número e eu tento acertar. 
* **O que me deu trabalho:** Entender como fazer o loop parar exatamente quando eu acertava e como usar o `Random` para o número não ser sempre o mesmo.
* **O toque especial:** Adicionei umas mensagens de "quase!" para o jogo não ser tão frustrante.

### 🔢 [Analisador de Números](./src/AnalisadorNumerico.java)
Esse aqui é um "faz-tudo". Você vai digitando números e ele vai guardando os dados até você digitar `0`.
* **O desafio:** Descobri na prática que se eu não usasse **Casting** `(double)`, o Java arredondava a média para baixo e o resultado ficava errado. 
* **O que ele entrega:** Soma total, quantos números você digitou, a média certinha e qual foi o maior valor de todos.

### ➗ [Contador de Pares](./src/ContadorPares.java)
Um filtro simples para mostrar apenas números pares.
* **Aprendizado chave:** Foi aqui que entendi para que serve o operador `%` (resto da divisão).
