# Analisador de Números - Java ☕

Fiz esse pequeno programa para treinar os fundamentos de Java que estou aprendendo no 1º semestre de Ciência da Computação.

## O que ele faz:
O código lê números que o usuário digita e só para quando recebe o valor `0`. No final, ele entrega:
* A soma de tudo e quantos números foram digitados.
* A média (usando `double` para não perder os decimais).
* O maior número da lista.

## O que eu pratiquei com ele:
* **Loop While:** Para manter o programa rodando.
* **Casting:** Usei `(double)` na divisão da média, se não o Java arredonda o valor errado.
* **If/Else:** Para filtrar o zero e não deixar o programa quebrar se o usuário não digitar nada.

## Como testar:
É só rodar o `Main.java` no IntelliJ e digitar os números no console.
